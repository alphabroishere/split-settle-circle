# SplitMate polish

## Goal
Refine the existing SplitMate dashboard and shared page styling without adding features or changing expense calculations or storage.

## Work
- Improve the dashboard’s phone-sized layout and visual hierarchy, especially the top actions, summary figures, balances, and recent activity.
- Tune shared page headers and panels to feel consistent while preserving SplitMate’s paper, ink, and marigold design.
- Make the spending chart’s container sizing stable to avoid the zero-size warning seen in preview telemetry.

## Validation
- Review the dashboard at phone and desktop widths, confirm no horizontal overflow, and check the chart and console.
- Run relevant existing checks and confirm the app preview has no build errors.
